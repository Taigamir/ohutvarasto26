# ohutvarasto26

## Varastonhallinta

Käynnistä verkkosovellus komennolla:

```sh
python src/index.py
```

Avaa sitten [http://127.0.0.1:8000](http://127.0.0.1:8000). Sovelluksessa voi
luoda useita nimettyjä varastoja, tarkastella niiden saldoja sekä lisätä ja
ottaa tavaraa. Määrät ilmoitetaan litroina. Varastotiedot säilyvät vain
sovelluksen käynnissäolon ajan.
